# Hingepoint – animated CSS 3D flip cards

- **Front:** product photo, name, maker and a one-line pitch
- **Back:** processor, display, weight and battery, a short description, the starting price and a "Buy now" button
- **Tech:** HTML and CSS only for the flip and animations. A hidden checkbox plus `:checked` flips each card.

**Live site:** https://Hazain1.github.io/css-3d-flip-cards/

## Files

- `index.html` – structure
- `style.css` – styling and animations
- `images/` – product photos (see `images/README.txt`)
